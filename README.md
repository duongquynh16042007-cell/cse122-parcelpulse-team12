# ParcelPulse — Giao diện đăng nhập (bản demo)

## Chạy thử
1. Giải nén thư mục.
2. Mở `index.html` bằng trình duyệt hoặc dùng Live Server trong VS Code.
3. Các file cần nằm cùng một thư mục:
   - `index.html`
   - `style.css`
   - `script.js`

## Có gì trong bản demo
- Giao diện responsive desktop / tablet / mobile.
- Chọn vai trò: Nhân viên giao hàng, Điều phối viên, Quản trị viên.
- Kiểm tra email/số điện thoại và mật khẩu bằng JavaScript.
- Hiện/ẩn mật khẩu.
- Ghi nhớ đăng nhập (phần giao diện).
- Thông báo lỗi và trạng thái demo.

## Lưu ý
Đây mới là frontend demo. Chưa có backend/API xác thực, chưa lưu phiên đăng nhập thật và checkbox ghi nhớ chưa lưu thông tin. Không nhập mật khẩu thật hoặc thông tin nhạy cảm.
